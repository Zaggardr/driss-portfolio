# Driss Zaggar — Portfolio

Modern portfolio for **Driss Zaggar**, State Engineer in Information & Communication Systems specialized in AI/Machine Learning.

## Stack
- Next.js + React + TypeScript
- Responsive CSS
- Vercel Analytics
- Lucide Icons

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy
Import **Zaggardr/driss-portfolio** into Vercel and deploy with the default Next.js settings.
